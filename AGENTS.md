# Reglas del proyecto TutorFlow

- El backend se debe diseñar en .NET 8 o superior.
- La interfaz web se debe hacer en Angular haciendo uso de TypeScript.
- Los commits deben usar dos bloques: `Generado-por: Codex`, una línea en blanco y luego `<tipo>: <detalle del commit>`.
- El historial de esta conversación se almacenará en la carpeta `/logs` y se actualizará a medida que avancemos.
